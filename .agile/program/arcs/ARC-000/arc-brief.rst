Intent
------
Define the foundational vision, goals, constraints, and glossary for the project so that all sprints have stable context.

Goals (measurable)
------------------
- Establish a repeatable AAS workflow that preserves staging discipline across sessions.
- Enable parallel workstreams using ARC-scoped sprint IDs.

Constraints
-----------
- Staging edits limited to `.agile/**` and `docs/**` (RST/Sphinx only).
- Execution requires explicit `EXECUTE SPRINT <SPRINT-ID>`.

Risk Notes
----------
- Too much ceremony can reduce adoption; templates must stay lightweight.
